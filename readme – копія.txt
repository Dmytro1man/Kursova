DriveSchool — коротка інструкція для запуску
============================================



КРОК 1. СТВОРИТИ БАЗУ ДАНИХ (один раз)
--------------------------------------

1) У WebStorm відкрийте термінал.
2) Перейдіть у папку backend. Для цього введіть команду і натисніть Enter:

   cd "project 127144 23.10.2026 12-37\backend"

cd backend

3) Встановіть залежності, які ще не встановлені. Для цього виконайте команду:

   npm install

4) Запустіть меню налаштування бази:

   npm run db:setup


Після пункту 3 база "driving_school" буде створена з тестовими даними.


КРОК 2. ЗАПУСТИТИ СЕРВЕР (backend)
----------------------------------

1) У тому ж терміналі переконайтесь, що ви в папці backend.
2) Виконайте:

   npm run dev



КРОК 4. ЗАПУСТИТИ САЙТ (frontend)
---------------------------------

1) Відкрийте ДРУГИЙ термінал у WebStorm:
   натисніть "+" у вікні Terminal (новий термінал).
2) Перейдіть у папку frontend:

   cd "project 127144 23.10.2026 12-37\frontend"
 cd frontend

3) Встановіть залежності, які ще не встановлені. Для цього виконайте команду:

   npm install

4) Запустіть сайт:

   npm run dev
